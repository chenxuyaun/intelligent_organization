# IO-001 · 定义面向其他团队的产品第一版

**状态：** 进行中（产品范围已收敛，部署与身份方案待定）  
**组织边界：** 用户 + AI 建设面向其他团队的产品；首个客户群暂定小型客服 / IT 支持团队。  
**任务负责人：** 用户  
**AI 执行角色：** 研究、产品拆解、实现、复核；这些是工作职责，不是多个独立 Agent。

## 任务目标

将当前单机客服实验台收敛为一款团队可以共同使用的产品：有真实成员身份、工作区边界、协作任务、受审核的共享经验和可复核的实际结果。产品需能让目标团队跑通“接任务 → 人机分工 → 执行 → 人工判断 → 记录实际结果 → 更新共享方法 → 下一次复用验证”。

## 完成标准

- 新团队能完成初始设置，至少两位成员用各自身份进入同一工作区。
- 成员可接力处理同一类问题，AI 建议、引用、人工判断、交接和实际结果均可追溯。
- 一个成员审核发布的经验能被另一位成员处理的后续相似问题找到，并能记录它是否有帮助。
- 工作区之间的数据不能互相读取或修改；成员不能执行角色未授权的动作。
- 演示样本、客户数据、AI 建议和人工结论在界面及记录中清楚区分。
- 产品可成功跑通不直接等于客户业务已改善；业务成效需要后续真实使用证据。

## 产品第一版切入口

暂定小型客服 / IT 支持团队的重复问题单。沿用现有工单、AI 建议、人工审核和知识复用流程，优先补齐真实成员身份、团队工作区与数据隔离。该切入口方便利用现有代码，但仍需客户访谈与试用验证。
